# Asset licenses

The starter models are original Voltonaut work created in Blender without downloaded assets. The PNGs under `assets-src/previews/` are renders of these same original models. The PWA icons under `../icons/` are an original Voltonaut drawing (a lightning bolt in a ring) authored for this project as SVG; the PNG, Apple-Touch and maskable variants are raster exports of that same SVG, rendered locally without third-party artwork or fonts.
